## Как пользоваться

**RizzML** превращает данные датчиков газлифтных скважин в суточный дебит нефти, воды и газа по каждой
скважине (виртуальная расходометрия, **VFM**) и интерпретирует каждую остановку как кривую
восстановления давления (гидродинамические исследования, **PTA**).

1. **Войдите** с почтой SOCAR. Язык можно сменить здесь, а позже в **Настройках**.
2. **Загрузка данных.** Перетащите исходные файлы, CSV или Excel. В списке под полем загрузки каждый
   распознанный файл становится зелёным. Или нажмите **Демо-данные** на Главной, чтобы запустить
   месторождение хакатона.
3. **Запустить анализ.** Очистка, расчёт дебитов и анализ исследований скважин занимают около
   30 секунд для 10 скважин за 9 месяцев. Затем приложение открывается на странице **Дебиты**,
   и все разделы становятся доступны.
4. **Смотрите результаты.** На каждой странице меню слева.
   - **Дебиты:** суточные нефть, вода и газ по скважинам. Точки — замеры скважин, если они загружены.
   - **Исследования скважин:** по каждой остановке проницаемость, скин, ΔP скин, наклон Хорнера и
     коэффициент совершенства, интерпретация простыми словами, графики Хорнера, log-log и история
     давления.
   - **Построить график:** любой график по результатам: динамика, кросс-плот, распределение,
     гистограмма или сравнение скважин. Данные графика скачиваются в CSV.
   - **Промысловые данные:** очищенная история датчиков по скважинам, остановки выделены.
   - **Качество данных:** что очистка нашла и исправила.
5. **Экспорт:** дебиты и результаты PTA в CSV или Excel, одна книга Excel со всем и отчёт HTML со
   всеми графиками.
6. **История** хранит ваши загрузки, анализы и скачанные файлы, чтобы открыть или скачать их снова.
   **Конвертер** переводит любой CSV в Excel и обратно.

## Ваши данные

| Файл | Нужен | Что содержит |
|---|---|---|
| `high_freq_data` | да | Поминутные датчики: `timestamp`, `well_name`, `whp_psia`, `whp_downstream_psia`, `dh_pressure_psia`, `dh_temperature_degf`, `annulus_pressure_psia`, `gas_lift_rate_mscfd` |
| `choke_events` | да | Изменения штуцера: `timestamp`, `well_name`, `choke_opening_pct` (0% = скважина остановлена) |
| `reservoir_pvt` | да | Строка на скважину: эффективная толщина, пористость, сжимаемость, радиус скважины, объёмный коэффициент и вязкость нефти, давление насыщения, отметка приведения, площадь дренирования |
| `well_completion` | да | Строка на скважину: глубина манометра, газлифтный клапан, размер НКТ, коллектор, растворённый газовый фактор, накопленная добыча |
| `well_tests` | нет | Замеренные дебиты. Добавляют проверку точности по ним, а замеры новее периода обучения модели обновляют модель по месяцам |

- Файл распознаётся по имени: достаточно, чтобы в нём было `high`, `choke`, `pvt`, `completion` или `test`.
- Файлы Excel читаются с первого листа. До 1 ГБ на файл.
- Очистка автоматическая: код пропуска −999.25, дубликаты строк и выбросы датчиков. Качество данных
  показывает, сколько чего найдено.

## Как это работает

**Дебиты (VFM).** Физическая модель, а не чёрный ящик.

- Дебит жидкости подчиняется закону течения через штуцер: размер штуцера, перепад давления на
  штуцере, устьевое давление и газожидкостный фактор.
- Перепад давления в НКТ делит его на нефть и воду; газ считается по растворённому газовому фактору.
- Подогнанная по 85 замерам, модель сама нашла учебный закон штуцера: размер штуцера в степени 2,06 и
  перепад давления в степени 0,47 (по учебнику: 2 и 0,5).
- На этих данных она обошла машинное обучение. При всего 85 замерах физика обобщает лучше.
- Замеры показывают примерно на 2,5% больше, чем обычные дни добычи (тестовый сепаратор работает при
  более низком давлении), и суточные дебиты на это скорректированы.
- Новые данные поддерживают модель актуальной. Если в загрузке есть замеры новее периода обучения
  модели, модель перенастраивается в начале каждого месяца по всем замерам, завершённым до этого
  месяца. Ни один день не рассчитывается по замеру из своего или более позднего месяца, а сам файл
  модели не меняется. Качество данных показывает, для каких месяцев модель перенастроена.
- Загрузка, начинающаяся после периода обучения, всё равно его использует: последнее известное
  положение штуцера и накопленная добыча нефти берутся из сохранённой истории обучения.

**Исследования скважин (PTA).** Остановки находятся там, где штуцер на 0%. Для каждой КВД:

- анализ Хорнера находит прямую радиального притока;
- затем модель скважины (влияние ствола, скин, радиальный приток, закрытая или бесконечная граница)
  подгоняется ко всем точкам КВД и даёт итоговые проницаемость и скин;
- используется рассчитанный суточный дебит нефти перед остановкой.

Забойный манометр стоит выше отметки приведения. Разница постоянна во время КВД, поэтому сокращается в
проницаемости, скине, наклоне и ΔP скин. Только p\* показывается и на манометре, и на отметке приведения.

**Точность.** Каждый замер предсказан только по более ранним данным:

| Фаза | Ошибка (MAPE) | Взвешенная по объёму (WAPE) | R² |
|---|---|---|---|
| Нефть | 2,56% | 2,33% | 0,998 |
| Вода | 3,82% | 3,48% | 0,996 |
| Газ | 5,65% | 4,61% | 0,994 |

Модель PTA совпадает с каждой КВД с точностью 0,03–0,08 psi (RMS).

**Ограничения.**

- Скважина, на которой модель не обучалась, получает среднее по месторождению, и приложение помечает
  её. Её дебиты ненадёжны, пока несколько замеров не откалибруют модель.
- Анализ исследований есть только для скважин, которые останавливались.
- Анализ КВД предполагает однофазную нефть. Здесь это верно: давление остаётся выше давления насыщения.
- Вход — демо-аккаунт, настоящей аутентификации пока нет.

## Термины

| Термин | Значение |
|---|---|
| VFM | Виртуальная расходометрия: дебиты по датчикам вместо тестового сепаратора или расходомера |
| PTA | Гидродинамические исследования: свойства пласта по изменению давления, здесь во время остановки |
| Остановка, КВД | Штуцер закрывается, приток прекращается, забойное давление растёт |
| Проницаемость (k, мД) | Насколько легко нефть течёт через породу |
| Скин (S) | Дополнительные потери давления у ствола. Положительный: загрязнение. Отрицательный: интенсификация |
| ΔP скин (psi) | Давление, потерянное на скин |
| Коэффициент совершенства | Какую долю потенциала без загрязнения даёт скважина |
| График Хорнера, наклон m | Давление от log((tp + Δt) / Δt). Прямой участок даёт m, а m даёт k |
| p\* | Давление, экстраполированное на бесконечно долгую остановку |
| Log-log, производная Бурде | Диагностический график. Ровная производная означает радиальный приток |
| MAPE, WAPE, R² | Средняя ошибка в %, ошибка в %, взвешенная по объёму, доля объяснённой изменчивости |
| Обводнённость, газовый фактор | Доля воды в жидкости; газ на баррель нефти |
| stb/d, Mscf/d, psia | Стандартные баррели в сутки, тысячи стандартных кубических футов в сутки, абсолютное давление |

## Проблемы

| Что вы видите | Что делать |
|---|---|
| Файл остаётся серым в списке | В имени должно быть `high`, `choke`, `pvt`, `completion` или `test`. Переименуйте |
| «Не удалось проанализировать данные» | Нет нужного столбца или он переименован. Сравните с разделом **Ваши данные** |
| Демо-данные заблокированы | На сервере нет демо-файла датчиков. Выполните там `git lfs pull` |
| У скважины нет результата исследования | Она не останавливалась: штуцер ни разу не был на 0% |
| «Нет в обученной модели» | Новая скважина. Её дебиты по среднему по месторождению |
| Страница просит сначала загрузить данные | Запустите анализ или откройте прежний из **Истории** |
| После смены темы страница перезагружается | Так и задумано. Вы вернётесь на ту же страницу с результатами |
| Загрузка идёт медленно | Поминутный файл около 260 МБ. Загружайте по офисной сети |
