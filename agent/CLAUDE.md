## Before you write code

Check `PROJECT_STATE.md` so you do not redo finished work, and `NEXT_STEPS.md`
so you do not collide with another agent's task.

## After you write code

**Update `PROJECT_STATE.md` in the same commit.** This is not optional — it is
the only shared record of where the project stands, and a stale one sends the
next session down a path that is already done or already ruled out. See the
*Workflow* section of `AGENTS.md` for exactly what to update.

## Conventions

Data lives in the repo under `data/`. `high_freq_data.csv` arrives via Git LFS,
so `git lfs install` is required before cloning or it is a 130-byte pointer.
`data/processed/` is gitignored and regenerated by the pipeline.

Team language is Azerbaijani; technical terms stay in English. Repo files,
code, comments and commit messages are written in English so the work stays
readable to the judges.
